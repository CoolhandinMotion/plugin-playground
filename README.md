# Plugin Playground

Welcome! This repository is the material for a hands-on workshop about
**agent plugins** — you'll install one, break one, build one, and discover a
few surprises along the way.

This is a guided session, not a self-paced tutorial. Think of it as a group
hike: your instructors set the pace, reveal what's next when the group is
ready, and know exactly where the interesting viewpoints are. If you're
reading this before the workshop, you don't need to prepare anything beyond
what your instructors have already told you.

- **All technical instructions** live in
  [workshop-instructions/](workshop-instructions/) — your instructors will
  tell you when to open which guide.
- **Questions during the session?** Ask the AI agent you're working with, or
  just raise a hand.

See you on the trail.
